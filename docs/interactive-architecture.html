Package layers

Design idea

Heavy ML backends are wrapped behind small interfaces. RAG orchestration composes services without owning model internals.

Public surface

QwenVLModel, QwenVLEmbedder, QwenVLReranker, MultimodalRAGPipeline, VisualRAGPipeline, CLIPEncoder, and document schemas/builders.

Indexing

VisualChunk objects become multimodal inputs and are stored in InMemoryVectorIndex.

Retrieval

The query is embedded, candidate_k items are retrieved, then optionally reranked.

Grounding

Selected original images, fused text, and source/page metadata are passed to Qwen3-VL generation.
