# ADR-001: Python 3.12 reference runtime

## Decision

Use Python 3.12 as the single declared and CI-tested runtime.

## Why

The target modern PyTorch / Transformers / SentenceTransformers stack supports Python 3.12, while using one tested baseline reduces matrix ambiguity for GPU-heavy examples.
